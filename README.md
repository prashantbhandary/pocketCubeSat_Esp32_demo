# PocketQube On-Board Computer (ESP32)

KiCad schematic and PCB for the ESP32 on-board computer of the 1.5U PocketQube educational satellite model.

## Paper
This project is described in a technical report:
**Electronics Design of a Low-Cost 1.5U PocketQube Educational Satellite Model with LoRa Telemetry and Stacked PCBs** — **Prashant Bhandari**, 2026. [Read the paper](https://bhandari-prashant.com.np/publications)
